# 第二阶段课程要求复核结论

## 核查依据与评价

逐项核对文件夹内《第五周任务讲解》《第六周任务讲解》《第7-9周任务讲解》，独立阅读实现和证据，并新增跨功能与边界反例。课程没有提供分值表，因此本结论评价明确要求的符合性，不虚构教师评分。

结论：第5周建模、第6周规范化/迁移、第7-9周SQL Server分层Web及阶段材料均有对应成果；原有表合理时保留、独立关系演示异常，符合第六周明确允许的做法。第二次核查实际发现五处上一轮测试未覆盖的缺陷，已修正并加入永久回归；当前提交版在课程范围内具备完整性、可演示性和可复现性。

## 质量边界与课堂准备

这是校园单店的课程应用，范围清楚，没有用未实现的支付退款、配方原料或公网部署充数。数据库应用角色是有效数据库身份降权；后端仍是可信边界，不把角色密码交给顾客，也不声称共享数据库角色能识别每名顾客。该边界与实际权限反例均已说明。

自动化、实际浏览器和SQL检查可证明上述已执行行为，不能替代每位同学理解与亲自演示。分工表不伪造开发时长或人工签字；三位成员应各自完成所分配的操作并补充本人验证记录。课堂应能解释：为什么不强行拆表、为什么历史价不随菜单价变、外码为什么不保证非空订单、一次确认失败为何不会部分扣库，以及顾客隐藏按钮之外的后端/数据库权限。
