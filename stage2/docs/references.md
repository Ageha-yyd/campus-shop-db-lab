# 技术参考

课程验收依据为文件夹中的《第五周任务讲解》《第六周任务讲解》《第7-9周任务讲解》；既有结构与样例以仓库第一阶段提交7b77969为准。

- [Flask Web Security](https://flask.palletsprojects.com/en/stable/web-security/)：会话与CSRF、输出安全。
- [SQL Server Application Roles](https://learn.microsoft.com/en-us/sql/relational-databases/security/authentication-access/application-roles?view=sql-server-ver17)：激活后有效连接权限变为应用角色；角色没有成员。
- [sys.sp_setapprole](https://learn.microsoft.com/en-us/sql/relational-databases/system-stored-procedures/sp-setapprole-transact-sql?view=sql-server-ver17)：顶层执行、连接加密、恢复cookie可选。
- [SQL Server Table Hints](https://learn.microsoft.com/en-us/sql/t-sql/queries/hints-transact-sql-table?view=sql-server-ver17)：UPDLOCK、HOLDLOCK与事务锁定。

设计和实现结论以本项目代码和实际SQL/浏览器证据为准；引用不替代执行验证。
