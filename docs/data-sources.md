## 虚构的教学数据

菜单名称与标价以外的数据均为教学演示而编造：库存快照、订单号、下单时间、购买数量、成交单价快照、取消状态、会员、员工和联系方式。它们用来演示关系、CRUD、查询和权限，并不代表蜜雪冰城或任何现实门店的订单、销量或库存。订单金额由虚构订单明细按菜单参考价计算。

如果教师要求真实交易样例，必须另行取得数据所有者授权并删除或替换个人身份信息；公开菜单价格不能替代真实订单、库存或顾客数据。
