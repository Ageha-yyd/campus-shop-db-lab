## 操作样例

订单、库存、员工和会员数据用于课堂操作练习，覆盖完成单、取消单、匿名购买、零销量、零消费和库存预警等情况。会员Phone字段保持NULL；唯一约束演示临时使用占位字符串，事务结束后回滚。

订单时间固定为2026-10-01至04，库存快照为2026-10-06 08:00 UTC，便于每次复现得到相同结果。库存记录当前可售杯数，历史订单记录成交明细，两者不自动联动。
