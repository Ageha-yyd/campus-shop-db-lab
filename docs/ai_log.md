# AI 使用记录

本实验使用 Codex 辅助SQL草稿、修改建议、文档整理和本机运行验证。以下记录主要用途、采纳修改及对应结果；三名组员的职责见 [小组分工](contribution.md)。

| 环节 | 辅助内容 | 本项目的采纳与修改 | 对应材料 |
| --- | --- | --- | --- |
| 关系模式与基础SQL | 六表结构、键约束和CRUD语句草稿 | 按奶茶店场景确定字段与关系；保留成交价快照、可空会员和事务回滚；将饮品、库存、订单及明细分别演示 | SQL01/03、数据字典 |
| 样例与业务查询 | 关联样例、聚合查询与边界检查建议 | 结合组内方案补充匿名单、取消单、零销量、零消费和阈值边界；区分订单数、杯数和销售额 | SQL02/04/05/08 |
| 执行问题排查 | 编码、ANSI设置、约束错误及权限检查建议 | 使用UTF-8和显式ANSI设置；反例核对错误号与约束名；权限检查包含允许和拒绝操作 | SQL06/07、执行记录 |
| 文档与运行材料 | 说明文字、清单整理；协助执行SQLCMD/SSMS并采集结果 | 保存最终SQL、完整运行输出、SSMS截图与文件校验信息；按第一至第四周要求组织报告 | README、阶段报告、result目录 |

## 主要修改决定

1. 场景采用标准饮品奶茶店，保持六表结构；库存记录可售杯数快照。
2. 组内方案整合后，为饮品设置独立预警阈值，会员汇总保留无消费会员。
3. 菜单更新只调整当前标价，历史成交价保留；CRUD、约束反例和权限演示的试验写入在事务结束时回滚。
4. 以数据库实际返回的行数、错误号、权限结果和验收断言确认语句效果，课堂讲解以最终脚本和运行结果为依据。
