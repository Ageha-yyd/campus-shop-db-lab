# AI 使用记录

## 输入

用户原始任务：“按照项目中的文件第一周到第四周的内容开始进行完成实验，就是第一阶段的任务，项目总览里面应该有”。本轮据此检索仓库路线、总览与父目录课程文件。没有把原始课件上传到外部 AI 服务，也没有请求生成真实个人数据。

## AI 候选与代理修改

| 环节 | AI 生成的候选内容 | 本轮代理所作的取舍/修改 | 验证证据与仍需学习者本人完成的事 |
| --- | --- | --- | --- |
| 场景与边界 | 原候选为校园小卖部，覆盖商品、库存、订单、明细、会员、员工 | 学习者随后明确选择奶茶店并指出希望更简单；采用固定标准饮品菜单，允许匿名订单，排除糖度/冰量/加料/配方、原料库存和采购补货 | `requirements.md`；范围根据学习者最新决定更新 |
| 模式 | 商品目录、库存快照、订单头、订单明细、会员、员工 | 订单明细保存成交时单价；会员外键可空；库存只表示快照，明确没有库存流水/扣减闭环 | `data-dictionary.md`、`01_schema.sql`；SQL Server 2025 实测。学习者需能解释行粒度、主键、候选键和外键 |
| SQL 实现 | 建库/建表、装载、CRUD、连接聚合、统计视图、约束反例和角色权限 | CRUD/角色测试写在回滚事务中；用无登录数据库用户验证权限，不创建密码或 Windows 登录；约束错误由 SQL Server 捕捉 | `sql/` 与 `result/`；未验证 SQL Server 2022、SSMS GUI、远程认证。学习者需在所用环境自行复跑并判断 |

## 学习者人工修改与验证

学习者已明确把场景从校园小卖部改为奶茶店，以降低场景复杂度。本轮把菜单缩减为固定标准饮品，不加入糖度/冰量选择、配料或原料库存。仍待本人审阅字段/结果并补充在 SSMS 中的复跑截图，以及能够解释的反例。脚本实测证明的是本机 SQL Server 2025 上本数据集的观察结果，不替代个人复核或答辩。
