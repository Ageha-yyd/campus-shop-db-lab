# 阶段一实验报告：数据库初建与 CRUD

## 目标与设计思路

本阶段按课程第 1–4 周任务把校园奶茶店需求转成 SQL Server 关系库，完成建库、装载、增删改查、多表查询、统计视图、数据库约束和不同角色授权。采用六张核心表。订单明细记录当时成交单价，避免菜单改价后覆盖历史交易；会员外键允许空值以保留匿名购买；库存仅是标准饮品可售杯数快照，不声称已实现配方、原料核算或下单扣减事务。

## 实验环境

Microsoft SQL Server 2025 Express，实例 `SQLEXPRESS`，Windows 集成认证，本机 SQLCMD 18 / ODBC Driver 18。用 `-C` 接受本机实例证书。具体服务器版本保存在 `result/server-version.txt`。本轮未通过 SSMS 界面执行，未测试 SQL Server 2022 或其他环境。

## 复现过程与观察

1. 从 `master` 创建新数据库 `MilkTeaShopV01`。
2. 按序执行六表 schema、样例装载、CRUD、查询、视图、非法约束输入和角色权限脚本。
3. CRUD 脚本在事务内展示新增、读取、修改、删除目标行，并在最后回滚，因此执行前后基线相同，可重复运行。
4. 样例查询按订单状态限制完成订单，订单明细粒度为一行一商品行。零销量商品通过 `LEFT JOIN` 保留，避免误把未销售商品过滤掉。
5. CHECK、UNIQUE、FK 拒绝负库存、重复订单号/手机号、孤儿订单明细和非法数量；有效对照行能够成功插入后回滚。
6. 店员演示用户能读商品/库存视图并新增订单头；改商品价格、删商品与直接读员工表失败。店长角色只获得六张业务表的维护权和视图读取权。演示用户没有登录凭证。

实际输出见 `../result/`。运行数量和错误号以输出文件为准，不能把预期错误文本代替数据库观察。

## 阶段总结

课程要求的原型脚本已在本机 SQL Server 2025 从新库复现，包含需求与边界、字段/键说明、六表建库装载、CRUD、多表和统计查询、三个视图、完整性反例、角色最小授权、AI记录和分工模板。最重要的取舍是保留交易时价格与匿名购买，同时不把未经设计的库存联动、支付、采购补货写成已实现能力。

## 限制与后续

- 结果目录保存命令行捕获的数据库输出，不是 SSMS 图形界面截图；如教师要求截图，需本人打开 SSMS 重跑并截图。
- 需要本人填写组员/个人分工，并确认奶茶店场景与课程小组要求。
- 可售杯数没有库存变更流水；订单完成/取消未与库存自动联动，糖度、冰量、加料和原料消耗未建模。
- 未覆盖真实登录账户、权限边界以外的应用层认证、并发/死锁、事务、支付、退款、备份恢复与 SQL Server 2022 兼容验证。
- SQLCMD 输出证明当前版本与种子数据下的行为；尚无独立学生迁移任务或课程掌握证据。
