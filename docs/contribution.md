# 小组分工

本项目由袁远冬、陆乐天、罗金浩三人分工协作，阶段一按需求与整合、数据与基础操作、查询与报告三个部分分配职责。仓库维护人为袁远冬。

| 成员 | 主要职责 | 对应文件与工作内容 |
| --- | --- | --- |
| 袁远冬 | 需求分析、关系模式设计、仓库维护、整体整合与复现 | 明确奶茶店业务流程和数据边界；整理六表关系与键；维护建库/建表脚本、README及复现入口；汇总各部分成果与运行记录。对应 `requirements.md`、SQL00/01、README和复现脚本。 |
| 陆乐天 | 数据字典、样例数据、增删改查、完整性约束 | 整理字段类型、域、默认值与空值；安排关联样例和边界数据；负责饮品/库存/订单及明细CRUD、约束正反例和基线核对。对应 `data-dictionary.md`、SQL02/03/06/08。 |
| 罗金浩 | 业务查询、统计视图、角色权限、报告与截图说明 | 负责连接、聚合、HAVING和子查询；整理饮品预警与会员统计视图、店员/店长权限；组织阶段报告及截图说明。对应 SQL04/05/07/11、`stage-report.md`、`evidence-checklist.md`。 |

## 协作与课堂演示安排

- 交叉复核：袁远冬核对样例与CRUD，陆乐天核对查询和统计结果，罗金浩核对表间关系与复现步骤。
- 袁远冬讲解需求、六表关系和从空库建库；陆乐天讲解字段、CRUD与约束反例；罗金浩讲解查询、视图与角色权限。
- 三人共用本仓库的最终SQL和运行结果，课堂演示按建库、数据操作、查询与权限的顺序进行。

组内材料的整合过程见 [方案整合记录](integration-notes.md)。
