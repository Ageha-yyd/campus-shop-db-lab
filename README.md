# 阶段一 v0.1：校园奶茶店数据库实验

独立的 SQL Server 课程小项目，按原始第 1–4 周任务完成需求、关系模式、六表样例、CRUD、查询、四个视图、完整性约束与最小角色权限。2026-10-06 已对当前脚本完成空库顺序复跑，并采集真实 SSMS 执行截图；技术验证通过。**学习者确认教师明确允许虚构教学样例**，因此不再将真实交易数据列为交付缺项。分工和两位同学的借鉴来源已记录，课程最终评分与个人现场讲解由教师确认。

## 场景与范围

校园单店出售固定标准饮品。六表分别记录饮品菜单、可售杯数快照、会员、员工、订单头及明细。支持匿名购买，保留历史成交价，完成销售统计排除取消单。每款饮品有独立预警阈值；达到或低于阈值时，建议补足到两倍阈值。该数字用于备售规划，实际制作仍需考虑原料和保质期。

本阶段未实现糖冰加料、原料配方、采购、自动制作、下单扣库存、积分、支付和退款。库存是盘点快照，与历史订单不自动联动。公开菜单参考与虚构交易的区别见 [数据来源](docs/data-sources.md)。

## 只依赖仓库复现

先安装 SQL Server、SQLCMD（ODBC 版）及 ODBC Driver，并给予当前 Windows 用户建库权限；本项目不打包软件安装程序。已验证：SQL Server 2025 Express `17.0.1000.7`、SQLCMD 18、ODBC Driver 18、SSMS `22.10.12217.157`。其他版本尚未实测。

在仓库根目录的 PowerShell 7 中执行：

```powershell
.\scripts
un-lab.ps1 -ServerInstance '.\SQLEXPRESS'
```

SQLCMD 不在 PATH 时，用 `-SqlcmdPath '实际的 SQLCMD.EXE 路径'`。脚本使用 Windows 集成认证与 UTF-8；`-C` 用于本机实验实例的证书。顺序固定为：

`00 → 01 → 02 → 09 → 03 → 04 → 05 → 06 → 07 → 08 → 10`

任一步失败立即停止，输出及脚本 SHA256 保存在 `result/verification.json`。同名数据库已存在时，脚本在写日志前拒绝执行，不会自动删除数据。需重新演练时，先备份并明确保留/改名原实验库。`00` 从服务器读取默认数据目录，文件名加唯一后缀，无本机硬编码路径。单独执行 SQL 时：`00` 连接 `master`，其余连接 `MilkTeaShopV01`。

种子数据全部在 `sql/02_seed.sql`，公开菜单引用快照在 `data/public-menu.csv`。运行时不访问网页、不读取父目录课件、同学目录或已有学习平台。
